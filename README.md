# OVA · Conversión de Magnitudes Físicas (Tiempo, Longitud, Masa y Volumen)

**Nombre del aprendiz:** _(completar con tu nombre antes de subir el repositorio)_

**Tema del OVA:** Conversión de magnitudes físicas escalares — tiempo, longitud, masa y volumen.

## Descripción corta

Objeto Virtual de Aprendizaje (OVA) desarrollado para la competencia *Aplicación de conocimientos
de las ciencias naturales de acuerdo con situaciones del contexto productivo y social* del programa
Tecnólogo en Análisis y Desarrollo de Software (SENA). Permite comprender y practicar la conversión
entre unidades de tiempo, longitud, masa y volumen mediante contenido explicativo, un conversor
interactivo animado con Canvas 2D y una evaluación con retroalimentación inmediata.

## Estructura del proyecto

```
/
├── index.html
├── README.md
├── css/
│   └── estilos.css
├── js/
│   ├── conversiones.js   → factores y funciones de conversión
│   ├── animacion.js      → animaciones con Canvas 2D
│   ├── evaluacion.js     → banco de preguntas, calificación y modal de retroalimentación
│   └── principal.js      → inicialización general y lógica del conversor interactivo
├── img/
└── assets/
```

## Cómo ejecutarlo

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` directamente en tu navegador (no requiere instalación
   ni dependencias, ya que todo el código es HTML, CSS y JavaScript vanilla).
3. Navega por las cuatro secciones desde el menú superior: Introducción, Contenidos,
   Actividad y Evaluación.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 con variables (`:root`) y media queries para diseño responsive básico
- JavaScript vanilla (sin frameworks), con nombres de variables y funciones en español
- Canvas 2D para animar y recrear visualmente el resultado de cada conversión
